Claude守护 使用说明
====================

版本：1.0.0

一、需要什么
  1. Windows 10 或 Windows 11 电脑
  2. 已经装好 Clash Verge（Clash Verge Rev），并且有能用的节点
  3. Edge 或 Chrome 浏览器（用来装配套插件）

二、安装（只要做一次）
  1. 把这个压缩包整个解压出来（不要在压缩包里直接双击）
  2. 双击「安装.bat」，按屏幕提示走完
     · 不需要管理员，不会开机自启
     · 装好后桌面会多一个「Claude守护」图标
  3. 以后重新安装新版，同样双击「安装.bat」即可，设置和账号资料不会丢

三、装浏览器插件「英文区域与字体探测限制」（每个浏览器各装一次）
  插件文件夹在：%USERPROFILE%\.claude-switcher\extension\yingwen-quyu-ziti
  （就是「你的用户文件夹」下面的 .claude-switcher\extension\yingwen-quyu-ziti，
   安装时屏幕上会显示完整位置，在选文件夹的窗口里直接粘贴这个路径也行）
  1. 打开 Edge，在地址栏输入 edge://extensions 回车
     （Chrome 输入 chrome://extensions）
  2. 打开页面上的「开发人员模式」开关（Chrome 叫「开发者模式」）
  3. 点「加载解压缩的扩展」（Chrome 叫「加载已解压的扩展程序」）
  4. 选上面那个插件文件夹，确定
  注意：
  · 装好以后不要移动、删除这个文件夹，否则插件会失效
  · Edge 有时会弹出「关闭开发人员模式扩展」的提示，点「保留」或右上角的叉，千万不要点「关闭」

四、每次使用
  1. 先在 Clash Verge 里手动点好这三样：
     · 打开「虚拟网卡」(TUN 模式)
     · 代理模式选「全局」
     · 选一个你要的国家的节点
  2. 双击桌面「Claude守护」打开
  3. 第一次用：在「出口设置」里选好「大洲」和「国家」（要和 Clash 里选的节点国家一致），
     在「浏览器」那里勾上你用的 Edge / Chrome，点「保存设置」
     （也可以勾「下次检查时自动认当前出口」，让它按你现在的出口自动填）
  4. 看检查列表：全部打勾、窗口上方显示「环境安全」就可以放心用 Claude
  5. 有红叉就点「一键修复」，修完再点「重新检查」
  6. 想看有没有新版本：点「检查更新」，会打开 https://github.com/mfksffitx-xi2/ClaudeGuard/releases ，自己下载安装

五、「一键修复」会做什么
  会自动改：
  · 电脑时区改成目标国家的时区
  · 电脑地区格式改成 en-US
  · 关掉 IPv6
  · 关掉系统共享定位，并禁止勾选的浏览器被网站要位置
  · 给勾选的浏览器加 WebRTC 防泄露设置
  · 把勾选的浏览器的网页首选语言改成英文（浏览器界面语言不变）
    —— 这一步要先把那个浏览器完全关掉，没关的话会提示你先关
  · 加一条防火墙规则，挡住 WebRTC 走的 UDP 端口
  · 打开 Clash 的 DNS 防泄露设置
  中间可能弹出「是否允许更改」的管理员窗口，点「是」。
  不会自动改的（要你自己在 Clash 里点）：虚拟网卡、全局模式、选节点。
  浏览器插件也没法自动装，要按第三步自己装。

六、重要提醒
  · 出口IP要和付款地址城市一致
  · 点窗口右上角的叉，程序不会退出，而是缩到右下角托盘里继续守护；
    要真正退出，在托盘图标上右键 →「退出」
  · 「保镖」：Claude守护 开着时，如果检查到网络不安全（比如出口国家不对、Clash 没开全局、共享定位开着），
    会自动关掉 Claude 和浏览器，防止露出真实地址。这是正常保护。
  · 「线路类型：机房」显示黄色只是提醒，说明节点 IP 是机房的，换住宅 IP 的节点才会变绿
  · 本工具仅供个人非商业使用，禁止商用（见 LICENSE.txt）
  · 卸载：双击「卸载.bat」，删账号资料前会先问你
