Derived from https://github.com/LinXiaoTao/FuckClaude ; original MIT copyright retained in LICENSE. Local configuration: no time zone, user agent, WebRTC, system font or IP changes.

Version 0.1.2 adds local fingerprint.js: fixed, separate Chrome/Edge Canvas readback seeds; small opaque sRGB canvases only. Does not alter the displayed canvas, UA, cookies, login state, WebGL, Worker or TLS. The fixed seeds are part of the local extension and survive normal browser restarts.

Version 0.1.3 excludes challenges.cloudflare.com and its subdomains from all content scripts and from Accept-Language rewriting for requests to or initiated by those domains. This preserves native challenge APIs and headers for compatibility; it does not solve challenges, fabricate tokens, or establish real-site acceptance.

Version 0.1.4 (2026-10-25) adds fontfamily.js: strips hidden CJK font names from inline style fontFamily / setProperty('font-family') so DOM width-probe font detection (FingerprintJS) falls back to base fonts. Page stylesheets untouched; Chinese text still renders via system fallback.
